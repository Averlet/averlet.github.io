# averlet.github.io

The coming-soon page for [Averlet](https://averlet.dev/), an error tracking tool for developers.

It's a static site served by GitHub Pages, with no build step. To preview it, open `index.html` in a browser.

The waitlist form posts to a Google Apps Script web app that saves signups in a Google Sheet.
